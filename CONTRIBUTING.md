# Contributing to SLN

Thank you for helping build this module. Follow these steps so every change can be traced and reviewed.

1. **Pick a task.** Find your assigned task under [Issues](../../issues) (or in the [task list](plan/master_task_list.md)) and comment that you are taking it.
2. **Branch.** Create a branch named `topic-short-name`, for example `topic-1-worked-example`.
3. **Write.** Use the [topic template](content/_topic-template.md). Beginner language, one idea at a time, every claim sourced.
4. **Commit.** Use a clear message such as `Add Topic 2 worked example`.
5. **Open a pull request** linked to the issue (`Closes #n`) using the PR template.
6. **Review.** A teammate checks correctness, beginner-friendliness and sources, then approves. Log the issue found, reviewer, correction and affected resources in the [review log](project-management/review_log.md).
7. **Propagate.** When a correction changes the Markdown, update every affected resource (study guide, test bank, slides, video scripts, mini lecture).

## Rules

- The latest Markdown in `content/` is the single source of truth.
- Cite sources in [references/sources.md](references/sources.md) as you write.
- Log significant AI assistance in the [AI-use log](project-management/ai_use_log.md) and say how you checked it.
- Do not commit student IDs, private conversations or personal logs.
- Keep filenames lowercase with hyphens, prefixed by their number.
