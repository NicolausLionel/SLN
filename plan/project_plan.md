# Project Plan | SLN AI Overview

## Project purpose

Produce an accessible introduction to AI for university beginners, spanning core concepts, how AI works, applications, limitations and responsible use.

## Deliverables

- Shared Markdown learning content as the reference source.
- Study Guide and Test Bank.
- Presentation slides and video tutorials.
- Four-minute live mini lecture: Introduction to AI and How AI Works.

## Scope boundaries

Include beginner-friendly explanations, practical examples and ethical questions. Exclude advanced model architecture, mathematical derivations, programming tutorials and detailed legal analysis.

## Quality gates

1. Verify references and terminology.
2. Have a different member review examples and answer keys.
3. Resolve corrections in Markdown before propagating changes to other deliverables.
4. Record evidence of actual review, contributions and AI assistance.
