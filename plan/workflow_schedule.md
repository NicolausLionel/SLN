## Collaboration protocol

1. Assign each task an owner and deadline.
2. Draft or edit content with meaningful commit messages.
3. Check factual accuracy and cite references.
4. Review before promoting content into slides or videos.
5. Log corrections and propagate them to affected resources.
6. Test the ZIP snapshot independently before submission.

**Communication:** WeChat/WhatsApp for coordination; GitHub commits, issues and pull requests where used for auditable project changes.
