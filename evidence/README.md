# 📂 Evidence Folder

This folder contains all the **evidence of work, deliverables, and project logs** for the SLN team project (*Persuasive Technology: Using Computers to Change What We Think and Do*). 

These files serve as proof of our progress, individual contributions, and final deliverables for each stage of the project. They are used to fill out our Personal Learning and Work Logs and to verify our final submissions.

---

## 📁 Folder Structure

To keep things organized, please place your files in the corresponding stage folder. If a folder doesn't exist yet, create it.
